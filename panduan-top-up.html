Siapkan data game sebelum memesan

Panduan Top Up

Data yang dibutuhkan dapat berbeda pada setiap game. Ikuti petunjuk pada formulir produk sebagai acuan utama.

Player ID / User ID

Buka profil atau menu akun di dalam game, lalu salin ID pemain yang ditampilkan. Jangan menebak atau menggunakan ID milik orang lain.

Server / Zone

Jika game menggunakan server, region, atau zone, pilih atau masukkan sesuai akun tujuan. Beberapa game tidak memerlukan data ini.

Periksa ulang sebelum checkout

Pastikan ID dan server sesuai. Kesalahan data tujuan dapat memengaruhi keberhasilan pengiriman dan penanganan komplain.

Jaga keamanan akun

Jangan mengirimkan password, kode OTP, recovery code, atau akses email kepada siapa pun. Untuk top up normal, gunakan hanya data yang diminta pada formulir resmi.
