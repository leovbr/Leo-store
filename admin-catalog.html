Kelola banner beranda & event / promo

Untuk banner di index.html: isi URL gambar dan URL tujuan klik. Contoh URL gambar: URL dari tab Gambar. Contoh URL tujuan: checkout.html?game=mobile-legends. Pastikan status aktif dan tanggal promo berlaku.

Banner halaman utama memakai promo aktif yang memiliki URL gambar dan URL tujuan. Isi kedua URL untuk mengatur banner.

Cukup pilih gambar dari perpustakaan atau pilih file foto lalu tekan Upload gambar banner. Tidak perlu menyalin URL gambar.
Pilih tujuan di atas: index.html (beranda), shop.html (katalog), checkout.html (pilih game untuk top up), atau order.html (halaman pesanan). URL akan terisi otomatis. Untuk halaman lain, pilih URL sendiri.

Banner bawaan saat ini: Mobile Legends, Free Fire, PUBG Mobile. Tekan tombol impor satu kali agar ketiganya menjadi entri yang bisa diedit/diaktifkan/nonaktifkan dari sini. Banner yang sudah ada tidak akan dihapus.
